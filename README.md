# JavaScript Snake Game

A classic browser-based Snake game built with vanilla HTML, CSS, and JavaScript.

## Features
- Smooth grid-based movement with Arrow keys or WASD
- Persistent High Score tracking via `localStorage`
- Zero dependencies—runs directly in any modern browser

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser, or host it directly using **GitHub Pages** (`Settings > Pages > Deploy from branch`).
[play live demo](https://monishabhushan14-creator.github.io/scaling-spoon/)
